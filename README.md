# Rumo ao Dead God

Tracker de conquistas de The Binding of Isaac: Repentance+. Lê o save do jogo ou o arquivo de conquistas da Steam, sugere a próxima conquista e o próximo personagem, e sorteia runs.

Site: https://joaopraiah.github.io/rumo-ao-dead-god/

- `template.html`: página (HTML/CSS/JS)
- `data/`: conquistas (wiki.gg), mapa de conquistas da Steam, save de exemplo
- `node build.js`: gera `index.html` e `docs/index.html` (o que vai pro GitHub Pages)
